# mvp-cut 改动说明

日期：2026-09-06  
基于：`implement-rag`  
目标：将经确认的 HTML demo 实装为聚焦核心功能的 Windows 桌面 MVP。

## 用户可见变化

- 正式界面收敛为 **专注、最近判定、我的案例、偏好设置** 四页。
- 采用深蓝侧栏、浅色工作区及专注计时环；桌面导航与顶底栏固定，最近判定独立成页。
- 可输入任务、选择时长、开始或结束专注，查看后端返回的剩余时间、活动、判断理由与案例引用数。
- 分心后展示系统级句子翻译窗口，支持提交译文、查看判分反馈与参考译文，以及答不出来时查看解析、换句重试。
- 界面语言与翻译目标语言独立设置，支持中文、英文、日语、韩语、法语、葡萄牙语。
- 可从历史截图或拦截窗口纠正判断，保存任务、实际状态和原因，供后续 AI 检索参考；可查看和删除案例。
- Guardian、自动日程和 Flow 不再随应用启动，旧模块与运行时数据保留；Session 结束不再弹出休息编排流程。

## 正确性与实现

- 新增 `/mvp` API，连接真实监控、案例存储及翻译判分，不使用 demo 的模拟状态或答案匹配。
- 挑战绑定当前 Session、拦截和题目 ID，过期题目不能解锁后续拦截。
- 无 API key、API 调用失败或非法判分结果不会放行；查看答案不算通过。
- 保存个人案例不等于异议通过，不解除当前拦截；历史反馈使用原记录的任务和截图。
- 模型调用异步执行，停止或替换 Session 后丢弃旧结果；拦截期间冻结计时，模型判分期间仍可结束。
- 案例变动和设置变动使判定缓存失效；样本文件读写增加跨实例线程锁。
- tkinter 继续复用常驻窗口，异步回调经 UI 队列执行；六语资源由 React 和 tkinter 共用。
- 调整 Electron 默认窗口尺寸；发布脚本显式包含语言资源，直接从后端入口冻结构建。

## 验证与限制

- 97 项全套后端测试通过；随后新增的待提交截图校验测试及所在 16 项测试组通过，共 98 项。
- 覆盖过期挑战、错误判分、停止期间的旧结果、案例 HTTP 完整链路及六语 Tk 控件渲染；窗口测试隔离在独立进程。
- 前端生产构建、Electron/API JavaScript 语法及 Git 空白检查通过。
- 尚未执行付费在线模型端到端实测或生成安装包。
- 当前新答题入口使用内置句子；自定义题库上传不在 MVP 界面范围内。

## 使用与回溯

关闭旧进程后运行根目录 `start_stable.bat`。API key 继续通过本地 `.env` 配置；代码不包含实际密钥。

- `mvp-demo-v1.0.0`：初版 demo。
- `mvp-demo-v1.1.0`：纠正为句子翻译并核对行为。
- `mvp-demo-v1.2.0`：最近判定独立页面与桌面布局。
- `mvp-app-v0.1.0`：正式 MVP 实装，提交 `ff6dd78`。
