## 设计范围

三个入口：专注、我的案例、偏好设置。桌面采用深蓝侧栏、浅色工作区、蓝色计时环；窄屏自动纵向排列。

1. 输入任务，选择 25 / 45 / 60 分钟，开始、结束、到期结束。
2. 实时倒计时与示例 AI 判定；底部 DEMO 控件可触发连接失败、重试和全屏式拦截预览。
3. 句子翻译：原文、译文输入、提交、参考译文和返回任务；答不出来可查看解析，但不算过关，需换句继续。
4. 最近记录与拦截页均可直接纠正判断，输入实际标签和原因，保存到个人案例；可查看、删除。
5. 界面语言和翻译目标语言独立设置：中文、英文、日语、韩语、法语、葡萄牙语。原句默认英文，目标为英文时改用中文；输入译文与参考译文使用目标语言，提示和解析使用界面语言。
6. 检查间隔、连续分心阈值收在折叠设置中，不干扰主流程。

## 演示说明

- 静态前端 demo，不连接后端，不进行真实截屏、AI 判定、题目生成或案例检索。状态、参考数、历史记录和题目为示例。
- 全屏式拦截只覆盖浏览器视口，可用退出按钮或 Escape 关闭；没有系统级锁屏。
- 保存个人案例不等于异议通过，不直接解锁。真实异议通过需后端复核，本 demo 不模拟 AI 接受异议。
- 界面偏好和案例保存在浏览器 localStorage（键 `focusguard.mvp-demo.v1`）；用户输入保留原文，不机器翻译。禁用存储时仍可体验，但刷新后不保留。
- 倒计时使用真实时间，仅拦截弹窗打开期间暂停（包括其内部纠错弹窗），普通历史纠错不暂停；刷新页面后回到未开始状态。
- 标注的画面为示意 UI，不是截屏。正式产品应以对应历史截图替换。
- 监督阈值仅保存偏好；演示中通过按钮触发拦截。AI 状态为固定样例，不随自定义任务生成。

## v1.1.0 行为核对

- **题型**：对齐默认 strict Session 的句子翻译；普通模式选择题不作为本 MVP 的答题方式。
- **题数**：目前 Session 调用 blocker.show 时沿用默认 1 题；Guardian 场景另传 3 题。MVP 去掉 Guardian，因此演示 1 题符合 Session 调用，而非统一宣称必须 3 题。
- **判分**：静态 demo 仅比对参考译文（忽略大小写、空白和标点），不声称能理解语义；实际后端由 AI 判断语义，应容许不同正确译法。
- **不会答**：查看答案不算通过，换句再试，与现有翻译流程一致。
- **个人案例与异议**：保存反馈只是供未来检索参考；后端 dispute 接受才解除拦截，二者不能混同。
- **记录归属**：历史示例保存其示例任务，而非用户此刻编辑的任务；拦截纠正使用当前任务。
- **实时检测与引用**：显式标为模拟状态，移除按案例总数伪造的引用数量。
- **计时**：仅拦截及其内嵌纠错冻结时间，查看历史纠错不冻结。
- **有意的 MVP 变化**：保留随时结束 Session（正式 strict 当前禁止停止）、在翻译拦截页新增案例纠正入口、移除工作/休息 Flow。这些来自已确定的 MVP 范围，尚未接入后端。
- **多语言待接线**：现有后端默认目标日语、部分解析固定中文；demo 的六语言切换是产品设计，正式产品需要同步修改后端与 tkinter。

旧版标签 `mvp-demo-v1.0.0` 保持不变；本次修订标签为 `mvp-demo-v1.1.0`。
